## 2. Architecture notes — where main's shape differs materially

### 2.1 `client/editor_ui.tsx` (main, 705 lines)

- Root is a Fragment (`editor_ui.tsx:459-697`). Children order: `FilterList` / `Prompt` / `Confirm` (conditional) → `<TopBar>` (`:493-647`) → profile `AnchoredMenu` (`:648-655`) → `<div id="sb-main">` with `NavigatorDock lhs`, plug `Panel lhs`, `#sb-editor`, plug `Panel rhs`, `NavigatorDock rhs` (`:656-666`) → `NavigatorModal` (`:667`) → `RevisionPreviewModal` (`:668`) → plug modal `.sb-modal-backdrop > .sb-modal > Panel` (`:669-687`) → bhs (navigator or plug, `:688-696`).
- **Keyed-panel arbitration:** the navigator (`client/navigator/ui/slots.ts` `useNavigatorSlot`) and plug panels (`viewState.panels`) share slot names. Effects at `:443-447` / `:453-457` hide the plug panel when the navigator claims `modal`/`bhs`; `editor.showPanel` syscall hides the navigator slot first (`client/plugos/syscalls/editor.ts:640-643`). Any modal/sidebar reskin must keep both sides of this handshake.
- **`sidebarSpacer`** (`:404-419`) passes `flex: mode` spacers into `TopBar lhs/rhs` so the title aligns with the editor column when docks are open; `.sb-nav-spacer` vs `.panel` class distinction is deliberate. The app-bar reskin keeps the `lhs`/`rhs` props.
- **Registrations block** `:3-35` — append-only; each slice adds its tags here with the same comment style.
- `Panel` requires a `slot` prop on main (`client/components/panel.tsx:6-17`); the fork's calls omit it.
- Main has no `isReadOnly` local; TopBar's `readOnly` is inline at `:644-646`. `Client.isReadOnlyMode()` (`client/client.ts:1111`) additionally includes `perm === "ro"` — CS-5 factors `const isReadOnly = viewState.uiOptions.forcedROMode || client.bootConfig.readOnly` (same expression, unchanged semantics).

### 2.3 Why `#sb-page-scroll` is dead, not deferred

`3961adfe` created `#sb-page-scroll` so the (then) scroll-snap container could own one shared scroll flow for FrontMatterPanel + non-sticky large app bar + CodeMirror in auto-height mode; `f491890c` repointed `client.ts`/`content_manager.ts`/`navigator.ts` scroll tracking at it; `de609e0b` added `snapToAppBar`. Scroll-snap is removed entirely (Jack). The raw-YAML card has no functional dependency on it (reads no scroll state). Meanwhile main has more scroll consumers than the fork did — `rebuildEditorState` scroll preservation (`client/client.ts:1014-1045`), `restoreScrollPosition` with visibility/MutationObserver (`content_manager.ts:837-895`), navigator history `scrollTop` (`navigator.ts:151`), page-top/page-bottom navigator docks rendered as CM block widgets (`client/codemirror/top_bottom_panels.ts`, `side: -2/2`), live-collab remote cursors.
